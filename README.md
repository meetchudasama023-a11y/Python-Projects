# Python-Projects

**Python Concepts user for Quiz Applications**

1. print() – Displays text, questions, options, and results.

2. input() – Accepts answers from the user.

3. Variables – Stores the score, user answers, and percentage.

4. Lists – Stores multiple quiz questions.

5. Dictionaries – Organizes each question, its options, and its correct answer.

6. for loops – Iterates through questions and their options.

7. if-else statements – Checks answers and determines the appropriate feedback.

8. elif statements – Evaluates the user's performance level.

9. upper() – Converts user input to uppercase for case-insensitive answer checking.

10. len() – Counts the total number of questions.

11. Arithmetic operators – Calculates the score percentage.

12. Formatted output – Presents the final quiz results clearly in the terminal.

**Python Concepts used for Rock-Paper Scissor Game**

1. import random – Imports Python's random module.

2. random.choice() – Selects a random item from a list.

3. input() – Accepts the player's choice.

4. print() – Displays choices, messages, and the result.

5. Variables – Stores the player's choice and the computer's choice.

6. Lists – Stores the available choices: rock, paper, and scissors.

7. lower() – Converts input to lowercase.

8. if, elif, and else – Control the game logic and determine the winner.

9. not in operator – Validates the player's choice against the available options.

10. == operator – Compares the player's choice with the computer's choice.

11. and and or operators – Combine conditions to determine winning combinations.

12. Line continuation (\) – Splits a long conditional statement across multiple lines.
